# Game Sheris

Folder ini adalah ruang khusus untuk game dan permainan.
Project utama (`editor-foto` dan `index.html`) tetap berada di luar folder ini dan tidak diubah.

## Struktur

Setiap game disimpan dalam foldernya sendiri dengan format nama `game-(nama game)`.

```
game-sheris/
├── README.md
├── game-contoh1/
│   └── index.html
└── game-contoh2/
    └── index.html
```

## Daftar Game

| Folder | Nama Game | Keterangan |
|---|---|---|
| `game-salingbercerita/` | Saling Bercerita | Game kartu obrolan untuk dua orang secara online. Dadu dua warna menentukan kartu Cokelat (masa depan, rencana, mimpi) atau Hijau (komitmen, kejujuran, kasih sayang). |

Daftar ini diperbarui setiap kali game baru ditambahkan.
