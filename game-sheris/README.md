# Game Sheris

Folder ini adalah ruang khusus untuk game dan permainan.
Project utama (`editor-foto` dan `index.html`) tetap berada di luar folder ini dan tidak diubah.

## Struktur

Setiap game disimpan dalam foldernya sendiri dengan format nama `game-(nama game)`.

```
game-sheris/
├── README.md
├── game-contoh1/
│   └── index.html
└── game-contoh2/
    └── index.html
```
